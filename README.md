#  Superstore Sales Dashboard
##  Project Overview
This project presents an interactive **Superstore Sales Dashboard** developed using **Power BI**. The dashboard provides insights into sales performance, profit analysis, product trends, regional performance, and customer segments using the Superstore dataset.
##  Objectives
- Analyze sales and profit performance.
- Identify top-performing products.
- Compare sales across categories and segments.
- Monitor regional profitability.
- Enable interactive filtering through slicers.
##  Tools Used
- Power BI
- Superstore Dataset
- Data Visualization Techniques
##  Dataset
The dataset contains information related to:
- Orders
- Sales
- Profit
- Quantity
- Categories
- Customer Segments
- Regions
- Order Dates
##  Dashboard Features
### KPI Cards
- Total Sales: **2.30M**
- Total Profit: **286.34K**
- Total Quantity Sold: **38K**
### Interactive Filters (Slicers)
- Category
- Order Date
- Region
- Segment
### Visualizations
- Top Products by Sales
- Sales Trend Analysis (Year, Quarter, Month, Day)
- Profit by Region
- Sales by Segment
- Sales by Category
## Key Insights
- Technology category generated the highest sales.
- Consumer segment contributed the largest share of total sales.
- West region recorded the highest profit.
- Certain products significantly outperformed others in sales volume.

##  How to Use
1. Download the repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Explore the dashboard using the available slicers and filters.
